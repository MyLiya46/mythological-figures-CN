# 神谱万象 · 中国神话人物知识图谱

> 一份开源的中国神话人物知识图谱可视化项目，将开天辟地、封神演义、西游取经、道庭佛国与民间俗神的万千神祇，梳理成一张可交互、可检索、可探索的关系网络。

纯粹静态网页，无需后端、无需构建。用浏览器直接打开 `index.html` 即可浏览整个中华神谱。

## 预览

打开 [index.html](index.html) 后：

- **滚轮缩放 / 空白拖拽**：自由漫游整张图谱；
- **悬停**：查看人物简介浮窗；
- **点选节点**：聚焦该人物并高亮其 N 度邻居（可在侧栏调节邻域深度）；
- **筛选 / 检索**：按神系、关系类型过滤，按姓名或别名搜索定位；
- **主题**：以「朱砂·鎏金·黛青·月白」为配色，暗色古风界面。

## 使用方式

项目零依赖构建，直接双击 `index.html` 或本地起一个静态服务器即可：

```bash
# 任意一个静态服务器均可，例如：
python -m http.server 8080
# 然后访问 http://localhost:8080
```

> 需保证 `index.html`、`data.js` 与 `vendor/` 目录处于同一文件夹下（网页会检测缺失并给出提示）。

## 项目结构

```
.
├── index.html        # 页面入口与交互逻辑（G6 图谱渲染 + 筛选/检索/聚焦）
├── data.js           # 图谱数据（window.SHENHUA_DATA，供页面直接加载）
├── data.json         # 同源 JSON 数据
├── src/              # 数据源分册与合并脚本
│   ├── combine.js    # 数据合并脚本
│   ├── meta.js       # 类别、层级与关系类型定义
│   ├── layout.js     # 预计算布局坐标
│   ├── data-*.js     # 各神系数据分册
│   └── ...
├── vendor/           # 第三方库（AntV G6 等）
└── build/            # 合并输出
```

## 数据格式

每个节点描述一个人物，每条边描述一组关系。核心字段示意：

```js
// 节点
{ id:"pangu", name:"盘古", category:"shanggu", level:0,
  desc:"开天辟地之神，垂死化身…", aliases:[...], shape:"creator", x:3154, y:1857 }

// 边
{ id:"e_xxx", source:"pangu", target:"nvwa", type:"blood", desc:"…" }
```

`level` 表示神格层级（0 创世·至高神 → 5 人间帝王·英雄·圣），`meta` 中的 `categories` / `edgeTypes` / `shapeMap` 定义了视觉映射。
